# Frozen Run Checklist

Before a run can be cited in the thesis, verify:

- [ ] benchmark question is clearly named
- [ ] target is explicit
- [ ] optimization metric is explicit
- [ ] recording-disjoint result is saved
- [ ] leave-one-family-out result is saved
- [ ] per-family summary exists
- [ ] per-recording summary exists
- [ ] config file exists
- [ ] split manifest exists
- [ ] predictions file exists
- [ ] metrics file exists
- [ ] environment snapshot exists
- [ ] script or notebook provenance is written down
- [ ] data version is written down
- [ ] main-text or appendix classification is assigned
